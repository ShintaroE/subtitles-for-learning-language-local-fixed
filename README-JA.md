# 別ID版の読み込み

この修正版は独自のキーとIDを持ち、名前は「Subtitles for LL（ローカル修正版）」です。
元の拡張機能とは設定・学習データが別になります。

1. chrome://extensions で「パッケージ化されていない拡張機能を読み込む」を選択。
2. この subtitles-for-ll-fixed フォルダを選択。
3. 「Subtitles for LL（ローカル修正版）」が追加されたことを確認。
4. 以前の「2.1.0 local patch」は無効のままにする。
5. 修正版を有効にし、Prime Videoを再読み込み。

元のストア版が一覧に戻るわけではありません。元のストア版を復元する場合は、以前の同一ID版の設定を必要に応じて控えてから、Chromeウェブストアから元の拡張機能を入れ直してください。
元と修正版を同時に有効にするとページ上の処理が重複するため、使用する方だけを有効にしてください。

ID参照の確認では、service workerに旧IDの条件がありましたが、MIN_DEBUG=trueにより常に同じ配布用コードを読み込むため、別IDでもこの分岐の動作は変わりません。
構文と模擬データのチェックは実施済み。Prime Videoと外部字幕サービスでの実動作は未確認です。
